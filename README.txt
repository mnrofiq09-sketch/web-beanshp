BEAN SHOP - WEBSITE MULTI HALAMAN

File:
- index.html       : Beranda
- layanan.html     : Layanan
- produk.html      : Etalase produk + filter kategori
- keunggulan.html  : Keunggulan Bean Shop
- kontak.html      : Kontak WhatsApp
- style.css        : CSS bersama
- script.js        : JavaScript bersama

PENTING:
Letakkan file logo Bean Shop milik Anda di folder "logo" dengan nama:
WhatsApp_Image_2026-11-11_at_08.12.12-removebg-preview.png

Cara menjalankan:
1. Ekstrak ZIP.
2. Pastikan file logo sudah berada di folder logo.
3. Buka index.html menggunakan browser atau jalankan melalui Live Server VS Code.

Navigasi sekarang menggunakan file HTML terpisah, bukan tautan section (#).
